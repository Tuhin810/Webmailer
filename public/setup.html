Google OAuth setup

Paste the credentials from your Google Cloud OAuth client. They save to the server instantly and can be changed any time — no restart needed.

Where to get these
  1. Google Cloud Console → APIs & Services → Credentials
  2. Create an OAuth 2.0 Client ID of type "Web application"
  3. Add the redirect URI above under "Authorised redirect URIs"
  4. Enable the Gmail API for the project
